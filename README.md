# Gestor de Despesas Pessoais

## Sobre o projeto

O Gestor de Despesas Pessoais é uma aplicação de consola desenvolvida em Python que permite registar e gerir despesas pessoais de forma simples.

Este projeto foi criado para praticar os fundamentos da programação em Python e desenvolver competências na criação de aplicações funcionais.

## Funcionalidades

- Registar despesas com descrição e valor.
- Validar os dados introduzidos pelo utilizador.
- Consultar a lista de despesas.
- Calcular o total de gastos.
- Eliminar despesas.
- Guardar os dados num ficheiro JSON.
- Recuperar as despesas quando o programa é iniciado novamente.

## Tecnologias utilizadas

- Python
- JSON
- Visual Studio Code

## Como executar

1. Instalar o [Python](https://www.python.org/downloads/) se ainda não estiver instalado.
2. Descarregar ou clonar este projeto.
3. Abrir a pasta `gestor_despesas` no Visual Studio Code.
4. Abrir o terminal no VS Code, através do menu **Terminal → Novo Terminal**.
5. Executar o comando:

   `python main.py`

6. Seguir as instruções apresentadas no terminal.
